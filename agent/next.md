### Risks / failure modes
- The sidebar markup itself could not be read during planning: the reference worktree path is blocked by the planning sandbox and the committed branch tip 9d89e66 is a pre-P12.7 ancestor with the old single-column layout. Mitigation: the six-view IA and controls distribution in this plan come from the reviewer's direct inspection and are corroborated by docs/backlog.md P13.5 and agent/staged/P13.5.md; the Worker re-inspects the worktree for visual detail and reports any placement delta instead of re-grouping on its own.
- Copying from the reference branch rather than referencing it would regress P12.7, P13 control-bridge and accounting functionality, since that branch predates them by roughly 10,000 deleted lines. Mitigation: explicit no-merge, no-cherry-pick, no-code-copy rule; visual reference only.
- Distributing controls into Projects and System risks blurring read-only analytics and mutation controls. Mitigation: retain an explicitly labelled, visually separated controls region in both views, enforced by a markup test.
- Hiding views invites conditional rendering, which would break refresh() helpers that assume hosts exist and would silently drop projections. Mitigation: all sections stay in the DOM, refresh() stays unconditional, enforced by a test that renders into an inactive view's host.
- P12.7 requires daemon/monitor/watchdog health, incident count, resource availability, freshness and last refresh in the first viewport; splitting content across views could regress this on deep links. Mitigation: badges and KPI strip are persistent chrome, not view content.
- CSP is default-src 'self'; any inline script or style for navigation would break the page and existing CSP assertions. Mitigation: all navigation logic lives in web/app.js.
- test_web_ui_refresh.py asserts an exact list of 35 DOM ids plus CSS and branding rules; a careless markup rewrite fails it. Mitigation: move markup without renaming ids and run the focused suite early.
- The Python server and src/web-server.ps1 keep parallel static asset tables, so a new asset registered in only one causes an environment-specific 404. Mitigation: stay on the existing three web files.
- Old bookmarks pointing at removed top-tab anchors could dead-end. Mitigation: legacy hash aliases plus deterministic fallback to Overview, covered by tests.
